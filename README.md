# 📌 dev-overtime

퇴근 이후의 시간을 활용해 학습하고, 만들고, 성장하는 과정을 기록하는 스터디 레포지토리입니다.  
작은 노력들을 꾸준히 쌓아가는 것을 목표로 합니다.

---

## 🧑‍💻 진행 방식

- 평일(월 ~ 금) 퇴근 후 자율적으로 학습을 진행합니다.
- 학습 내용은 정리하여 Pull Request(PR) 형태로 기록합니다.
- 코드, 개념 정리, 트러블슈팅 등 어떤 형태든 학습 결과를 남깁니다.

---

## 📚 학습 범위

- 기술(Tech) 관련된 모든 주제 가능
- 백엔드, 프론트엔드, 인프라, 데이터베이스 등 제한 없음
- 개발 외에도 생산성, 개발 문화 등 확장 가능

---

## 🔄 PR 규칙

### 1. PR 필수 내용
- 학습한 내용 정리
- 코드 또는 예제 (가능한 경우)
- 느낀 점 또는 개선 포인트

---

### 2. 피드백 과정
- PR 생성 후 코드 리뷰 도구(CodeRabbit 등)를 활용하여 피드백을 받습니다.
- 피드백 내용을 반영하거나 추가 학습을 진행합니다.

---

### 3. 불참 규칙
- 평일 5일 모두 참여는 필수가 아닙니다.
- **참여하지 못한 경우에도 반드시 PR을 생성해야 합니다.**
- PR에는 아래 내용을 포함합니다:
  - 불참 사유
  - (가능하다면) 간단한 회고 또는 짧은 기록

---

## 📈 목표

- 꾸준한 학습 습관 형성
- 코드 품질 개선 및 피드백 문화 익숙해지기
- 단순 학습이 아닌 "기록 + 개선" 중심의 성장

---

## 💡 규칙 요약

- 평일 기준 자유롭게 참여
- 학습 시 반드시 PR 생성
- 미참여 시에도 사유 포함 PR 생성
- 피드백 받고 개선까지 진행
